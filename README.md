# NEStalgia

A podcast covering the NES library one game at a time: history, development stories, trivia, and the **Essential Games List Vote**.

## Repo layout

| Folder | What's in it |
| --- | --- |
| `episodes/` | Episode outlines and show notes, one file per game |
| `research/` | Deep-dive research and reference material (e.g. the NES Zapper) |
| `assets/branding/` | Logos, social, Twitch, Patreon and web art |

Audio, Audition sessions, and PSDs are kept out of the repo (see `.gitignore`).
