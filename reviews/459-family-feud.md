# 459 - Family Feud

Beam Software made it and GameTek published it in 1991. The game says you already know how to play, and mostly that is true: a recognizable show format, a pixelated host who kisses the women, a board of survey answers. We all played it alone against the computer, which we agreed is a lonely way to spend an evening, then compared notes on odd questions.

### How it plays

- **The rules.** Five-person families face off, answers are ranked by how many of 100 surveyed people gave them, and you get 45 seconds to type one. Reach 200 points and you go to Fast Money.
- **The keyboard.** It is not QWERTY, but it is a few rows of letters instead of Jeopardy's single line, so nobody felt rushed.
- **The goal.** Winning means banking $20,000, which earns a congratulations screen. Not much for a family of five.

### The answer judge

- **Generous matching.** It took "face" for the answer "mouth" and "but" for "behind".
- **Odd gaps.** "Chest" earned an X, then the board flipped over "breasts". "Legs" earned an X while "thighs" was the answer. "Chris" was rejected, "Christopher" was not.
- **Fast Money zeros.** "Sunscreen" and "sunglasses" for something you use in the summer both scored nothing, and so did "leather" and "rain" for a kind of jacket. You never see what beat you.
- **The computer never guesses.** It only shows up on the board when it is right, which dodges the garbled speech problem Jeopardy had. If it reaches 200 first, a screen says it declined Fast Money due to tax considerations.

### The questions

- **Unusual pets.** We said snake, and it was the number one answer. Lion was accepted too, which is less an unusual pet than one that gets you locked up. On an emulator with rewind, we tried rabbits, hamsters, lizards, mice, rats, hedgehogs and tigers, and none were on the board.
- **Dull ones.** One question was the age girls start keeping a diary, and the answers were nine through 16. Another asked how long a mattress lasts, with answers running up to 100.
- **A defense.** The manual says these were the show's own survey questions, so we guessed they were the ones that did not play well on air.

### The host and the sequels

The pixelated host does an about-face with the men, so we never see his face. Richard Dawson hosted the original run from 1976 to 1985, and Ray Combs took over the 1988 revival. The Super Nintendo and Genesis versions use Combs and add the Bullseye round, the 3DO version goes back to Dawson, and the PlayStation game has Louie Anderson in full motion video. Family Feud Decades on the Wii has no host choice, and the 2010 Edition has you swing the Wii remote at the buzzer.

### The bottom line

Skip it. Nobody voted it onto the Essential Games List, and we argued that points in a video game cannot stand in for winning something, which sinks these game show games. Joe called it the best of the NES game show games so far, and two players could get a few rounds out of it.
