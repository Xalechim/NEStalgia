# Reviews

One written review per episode, named like the transcripts and show notes: `NNN-game-name.md` (for example `002-baseball.md`).
The website shows it as the first tab, **Review**, on that episode's page, with the verdict from the spreadsheet above it.

Format: an optional first line `# 002 - Baseball` (not shown), then plain Markdown. The ones so far use short paragraphs and `###` sections
("What it gets right", "Where it falls apart", "The bottom line"). Reviews are written from what the hosts said in the episode's transcript,
in the show's voice ("we"), without crediting a quote to a host unless the transcript makes the speaker clear.
Never write "one of us", "some of us", "a couple of us" and the like; it reads as machine-written. Say "we", name the host when the transcript
makes it clear, or leave the attribution out.
